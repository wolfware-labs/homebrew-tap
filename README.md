# Wolfware Homebrew Tap

Homebrew formulae for [Wolfware](https://github.com/wolfware-labs) tools.

## Usage

```sh
brew install wolfware-labs/tap/<formula>
```

or tap once, then install by name:

```sh
brew tap wolfware-labs/tap
brew install <formula>
```

## Formulae

- `moonlit` — build and release automation engine ([repo](https://github.com/wolfware-labs/moonlit))

Formulae are published automatically by each project's release pipeline.
